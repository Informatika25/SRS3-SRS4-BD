# СРС 3–4. Оформление Django-приложения, Bootstrap и статические файлы

Учебный проект по дисциплине **«Структура программного обеспечения и базы данных»**.

## Выполнено

* подключён **Bootstrap 5 локально**, без CDN;
* настроена работа со статическими файлами Django (`CSS`, `JS`);
* создан общий шаблон `base.html`;
* добавлена навигационная панель;
* оформлены страницы входа, профиля и списка курсов;
* создан собственный `style.css`;
* выполнена сборка статики с помощью `collectstatic`.

## Используемые технологии

* Python
* Django 5.x
* Bootstrap 5
* HTML5 / CSS3

## Установка и запуск
Клонировать репозиторий:
```bash
git clone https://github.com/Informatika25/SRS3-SRS4-BD.git
cd SRS3-SRS4-BD
```
Создать виртуальное оркужение и устнановить Django:
```bash
python -m venv venv
venv\Scripts\activate
pip install Django
```
Выполнить миграции, собрать статистику и запустить проект:
```bash
python manage.py migrate
python manage.py collectstatic --noinput
python manage.py runserver
```

После запуска:

```text
http://127.0.0.1:8000/
```
